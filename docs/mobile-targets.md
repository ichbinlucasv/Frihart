# Mobile targets (planned)

**Status: planned.** No Frihart mobile builds, packages, or stores
exist yet. This page is a target map, not a shipping claim.

## After Linux desktop

Desktop Linux must be **good, stable, and fast** first — see
[ROADMAP.md](../ROADMAP.md) platform order and
[packaging/linux/README.md](../packaging/linux/README.md). Only then
does campaign **H** (other OS / mobile) leave park.

## Priority phone targets

When mobile work starts, these alternative / Linux-leaning phones are
**first-class** targets and must work great (stable + fast) — not as an
afterthought behind stock Google Android:

| Target | Notes |
| --- | --- |
| **GrapheneOS** | Hardened Android-derived. Priority phone port; **not** free desktop Linux. |
| **Jolla (Sailfish OS)** | Linux-leaning phone OS. |
| **Volla Phone OS** | Linux-leaning / free-software phone line. |
| Similar alt phones | Same priority track when they fit the stance. |

Stock Android, Windows, and macOS remain parked paid ports until the
Linux desktop quality bar clears; alt phones share the mobile priority
track once that work begins.

## Pricing

Packaged mobile / non-Linux builds (when they exist) are **€100
lifetime** — same model as HashChat Android: one-time, local key, no
license server, no Frihart account. Desktop Linux stays free.

Details: [pricing.md](pricing.md).

## What this is not

- Not a release checklist with dates.
- Not a promise that GrapheneOS / Sailfish / Volla packages are available.
- Not free desktop Linux packaging (`packaging/arch`, `fedora`,
  `debian`, `linux` stay Linux-desktop only).
