# Fedora package

Fedora-family desktop Linux package (`frihart.spec`), including the
usual base for **Qubes** Fedora templates.

This is **desktop Linux only** (campaign F). Ship a stable, fast
desktop binary here before mobile / other-OS packaging — see
[../linux/README.md](../linux/README.md) and
[docs/mobile-targets.md](../../docs/mobile-targets.md).

Build with `rpmbuild` against this tree when packaging. Qubes AppVM /
DisposableVM OPSEC: [../qubes/README.md](../qubes/README.md).
