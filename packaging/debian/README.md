# Debian / Ubuntu / Mint package

Debian-family desktop Linux packaging. Linux Mint is the primary
target in this family; the same `.deb` notes cover Ubuntu and plain
Debian. Tails and Qubes Debian templates reuse this tree with extra
OPSEC rules.

This is **desktop Linux only** (campaign F). The product lock is
stable + fast on desktop Linux before any packaged mobile port — see
[../linux/README.md](../linux/README.md) and
[docs/mobile-targets.md](../../docs/mobile-targets.md).

Build with `dpkg-buildpackage` when packaging. Tails amnesic notes:
[../tails/README.md](../tails/README.md). Qubes:
[../qubes/README.md](../qubes/README.md).
